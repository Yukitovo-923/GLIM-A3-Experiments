# SupCon-01 预先固定的实验配置

研究问题是跨句子 UID 的文本情感恢复。S0 与 S1 均沿用 Affect-Codebook-01 的 A1 分类部分。1024 维 EEG 句向量用训练 trial 的各维均值、样本标准差（下限 1e−5）标准化，经 1024→256 线性投影、L2 归一化后得到 z。分类器读取 16z，经 256→12、GELU、12→3 输出 logits。每组 265,523 个可训练参数。标签只用于训练采样、计算损失和事后评估。

| 项目 | 训练前确定的取值 |
|---|---|
| 数据 | ZuCo1 Task1-SR，训练 320 UID，验证 40 UID。仅读取已有 train.pt / val.pt，复核冻结 V3 epoch 46 的来源记录、SHA256 和 split 元数据 |
| 计算 | CPU、FP32，确定性运算，同种子共用初始权重与预生成的有序 batch |
| 随机种子 | 42、43、44，报告全部 |
| 优化 | Adam，学习率 0.0003，默认 betas，无 weight decay，梯度范数上限 1 |
| 预算与选模 | 每组 52 次更新，batch 63，无累积。采用固定末步，不比较中间验证结果。52 步与上轮 A1 被选中的一轮更新数一致 |
| S0 / S1 | CE / CE + 0.1 × SupCon。两组对同一投影输出反传 |
| SupCon | 温度 0.1，在单位向量的余弦上打分。先对每个 anchor 的合法正样本平均负 log 概率，再对有效 anchor 平均。分母为所有不同 UID 的正负样本 |
| 权重依据 | batch 63 中均匀分配概率时，每个正对的负 log 概率约为 ln(62)=4.13。乘 0.1 后约为 0.41，相对三类均匀 CE 的 1.10 作为辅助监督。温度 0.1 延续上一轮对归一化余弦的缩放尺度。本轮不搜索二者 |
| 主要指标 | 验证 UID Macro-F1、Balanced Accuracy。对每个 UID 的 trial 概率先平均再取 argmax |
| 配套证据 | 逐类 recall、混淆矩阵、预测比例、训练减验证 gap。以每个 UID 的平均单位 trial 投影再归一化计算跨 UID 余弦和验证→训练 1-NN，同 UID 排除 |
| 对照 | 1-NN 以训练 UID 类频率与验证类频率的内积作期望基线，另给多数类基线；固定近邻身份后置换训练 UID 标签 5,000 次，保留类频率 |
| 混杂与不确定性 | 按类别均衡 UID，轮换被试 trial；用训练 UID 句长三分位分箱作近邻敏感性检查，另用不重叠被试组构建查询/供体。检查同一组 40 个验证 UID 上三种子的配对差异 |

普通头与 SupCon 须使用相同批次、初始参数、归一化和预算。若属性指标及跨 UID 检索没有一致改善，暂缓生成阶段。验证 UID 已用于以前的诊断，所有推断限于该验证集。
