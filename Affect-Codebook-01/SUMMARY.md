# Affect-Codebook-01 · Seed 42 验证结论

**码本已成功更新并参与自由生成；本轮没有得到跨 UID 的情感恢复或生成质量增益。建议暂缓扩展 Topic Expert 和多专家。**

| 研究问题 | 本次观测 |
|---|---|
| 码本能否训练？ | 真实 EEG smoke 的 CE 从 0.9766 降到 0.00834。投影和码本均有有限非零梯度，码本参数变化 L2 为 0.1237。 |
| 与普通分类头相比？ | 阶段一训练 UID Macro-F1 均为 1.000；验证 A1 为 0.2274，A2 为 0.1887。A2 验证 Negative/Neutral recall 均为零。 |
| 是否塌缩？ | 存在明显的组内塌缩及 Positive 偏置。生成阶段结束后验证有 4/12 个活跃码，UID 等权困惑度 2.714；40 个验证 UID 中 37 个被判为 Positive。|
| 能否改变 Decoder？ | 第 2 次生成更新中 LM 对码本的梯度范数为 0.461。保持同一 EEG，替换为另一训练活跃码，386/406 条自由生成字符串改变。 |
| 生成质量如何？ | 正确 EEG 下，A2 的 BERTScore F1 为 0.83682，低于 A0 的 0.84064 和 A1 的 0.84198。A2−A1 的 ROUGE-L 为 −0.00949，BERTScore F1 为 −0.00516。 |
| 正确 EEG 的优势是否增强？ | A2 正确减错配的 BERTScore F1 为 −0.00076，配对 UID 95% 区间 [−0.00402, +0.00260]。相对 A0、A1 的差中差也都跨零。 |
| 是否值得扩展？ | 现有结果支持保留可运行实现，暂缓增加专家。本轮没有直接测试 Topic 的可恢复性。 |

**验证范围。** A800 80GB 上使用 V3 epoch 46，320 个训练 UID、40 个验证 UID，主模型全冻结。每项生成结果先按同一 UID 的多个 trial 求平均，再按 UID 等权汇总。本轮没有构建 Test 数据集或评估 Test。历史 EPA 只提供“训练内拟合、跨 UID 预测偏向 Positive”的背景，其损失、冻结范围与训练预算均与本轮不同。

**初步迹象。** A1 的生成较短且重复较少，部分词面指标高于 A0。A2 换成另一活跃码时 BERTScore 反而比自然选码高，提示当前选码与参考句语义之间的对应关系较弱。人工干预属于诊断条件。

**仍待检验的解释。** 冻结的 V3 句向量可能保留了训练 UID 的可识别信息，而对未见 UID 缺少可迁移的文本情感信号；也可能是当前分组 CE 和路由方式使类内多个码竞争不足。这个 pilot 无法区分这些原因。单 seed、40 个反复使用过的验证 UID、一次错配映射限定了推断范围。
