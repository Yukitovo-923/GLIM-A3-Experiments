# Affect-Supervision-01：GLIM + EPA 结果报告

**完成时间：**2026-11-11 22:37（北京时间）  
**结论：**在既有 V3 情感监督的 GLIM 上再加 EPA（权重 0.2），本次实验没有显示稳定的 EEG-to-Text 生成收益，也没有改善情感属性恢复。正确 EEG 在教师强制 LM Loss 上优于同被试错配 EEG，但这一差异没有稳定转化为 BLEU、ROUGE-L 或 BERTScore 收益。

## 设计与审计

- 初始化：B0/B1、种子 42/43/44 都从同一个 V3 `A3-full` epoch 46 checkpoint 初始化；原始 215 个共享权重逐值相同。原 checkpoint SHA256：`fe30e8cfc308aa464caa6d460b82bd1720c857d029c9944758b9d0661884c337`。训练后重新核验，哈希未变。
- 数据：ZuCo1 Task1-SR 共 4,139 个有效 EEG trial、400 个独立 UID、12 名被试。train/val/test 为 320/40/40 UID、3,316/406/417 trial，按 UID 隔离。句子标签为 Negative 123、Neutral 137、Positive 140。标签匹配无冲突。完整被试分布见 `data_audit.json`。
- B0 延续 V3：`0.5 CLIP + 0.5 LM + 1.0 VQ + 0.2 原离散情感 CE`。B1 在完全相同的结构、生成路径和基础损失上，再加 `0.2 EPA CE`；两组均保留原情感头及 Attribute Token。因此本轮检验的是 EPA 的**增量效果**，不是“有无任何情感监督”。
- B1：EEG 侧 `q_x` 向量 → `Linear(1024,1024)` → L2 归一化 → 三个冻结文本原型余弦相似度 / `τ=0.07` → CE。原型 `[3,1024]`，由 320 个训练 UID 的冻结 Flan-T5-Large Encoder 表征构建，SHA256 `ceaaccee85eee260c8c6e540bf441fced6421b2912aa9014d246e0cd55f5f31d`。测试文本未参与原型计算。
- 统一配置：Adam，学习率 `1e-4`，weight decay 0，train/val/test batch 72/24/24，A800 BF16，最多 10 epoch，按验证 LM Loss 早停（patience 4），beam 2、最长 64 token。每个种子配对训练。完整配置见 `configs/common.json`。
- EPA-01 原实验从 `A3-no-attribute` 初始化，移除 V3 Attribute Token，且训练数据范围、50 epoch 预算与本轮不同；其模型类不能直接加载指定的 V3 checkpoint。本轮只复用温度、EPA 权重和训练集原型构建思路，在独立目录实现。

## EEG 是否参与生成

错配方案在**同一被试内**将每条测试 trial 的 EEG 换成另一 UID 的 EEG，保持提示和参考文本不变；每组每种子均对完整 417 trial 运行。正确配对 EEG 相对错配 EEG 的 LM Loss 平均下降：B0 `0.32718 ± 0.08577`，B1 `0.35345 ± 0.05524`。六个种子×组别组合的 LM Loss 均朝正确配对有利的方向变化。这证明模型的条件似然使用 EEG 信息。

生成指标证据较弱：正确配对减错配的 BERTScore F1 为 B0 `+0.00003 ± 0.00187`、B1 `−0.00004 ± 0.00052`；ROUGE-L 为 B0 `−0.00118 ± 0.00557`、B1 `−0.00201 ± 0.00309`。因此尚不能确认 EEG 对最终自由生成文本带来稳定质量收益，也不能将 LM Loss 差异直接等同于语义恢复。

## 结论与下一步

1. **EPA 是否改善文本生成？** 本次固定配置下，没有稳定证据；主要语义指标 BERTScore 与 BLEU-2/4 下降。
2. **情感恢复是否更好？** 没有。B1 原头的 Macro-F1 低于 B0，EPA 读出更低且偏向 Positive。
3. **是否损害原整体语义对齐？** 测试 LM Loss 均值小幅增加 `0.03246`，但种子差异较大，不能断言显著恶化；BERTScore 均值略降，未见可确认的收益。
4. **EEG 是否真正参与？** 条件似然层面是；自由生成质量层面的证据不足。
5. **是否值得直接扩展多离散专家码本？** 当前不支持直接扩展。先在新的验证划分上调查 EPA 偏向 Positive 的原因，包括原型间相似度、类别均衡、EEG `q_x` 与原型的几何距离，以及学习率导致的首轮后验证 LM Loss 恶化；只用验证集决定下一轮设计，再以新的封存测试集复验。

**解释边界：**V3 已带情感监督，本实验只能评价额外 EPA 的效果；测试集仅 40 个 UID，且先前 Text-space Audit 已对相同测试句做过原型诊断，所以它不是完全首见盲测。两组在本次评估中没有使用测试集选择 checkpoint、原型、温度或权重。
