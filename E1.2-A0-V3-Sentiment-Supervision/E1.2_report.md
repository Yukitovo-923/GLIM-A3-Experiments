## 2. 输入、划分与监督

当前源码中，两者共用的 GLIM EEG Encoder 输出 96×256，Aligner 投影为 1024 维。原 GLIM `train.py` 使用同一 EEG pickle 接口，训练损失代码为 `0.5 × CLIP + 0.5 × LM + 0 × 原 commitment`；虽读取情感标签并在评估时计算情感分类，但未把显式情感交叉熵加入训练损失。A0 独立实例上的最终运行配置尚未取得，故“独立 A0 确实无显式情感损失”目前由原源码和历史日志支持，不能用缺失的 A0 checkpoint 再次验证。

V3 配置：batch size 72、Adam、学习率 `1e-4`、BF16、`A3-full`、余弦 VQ、128×256 码本、离散情感损失权重 0.2、VQ 权重 1、CLIP/LM 各 0.5、连续情感损失权重 0；情感属性 token 注入文本生成，预测概率对 LM 梯度默认 detach。离散情感损失经 VQ 的 STE 能影响共享 EEG Encoder 和 VQ projection，VQ loss 与文本损失也会影响共享部分。因此即使获得 A0 权重，A0/V3 差异也不等同于情感监督的单独作用。

V3、A3 Revised 和 E1 的已保存 `split_manifest.csv` SHA256 均为 `13ba43e80a6e90365bbabf2ced66538198597c9c749d6fdd77a3eb6ec374bb17`。E1 审计的 ZuCo1 Task 1：train 320 句/3,316 trial、val 40 句/406 trial、test 40 句/417 trial，V3 内句子 UID 跨划分重叠为零。**A0 独立运行的 manifest 缺失，不能证实它使用同一划分。** 发布版 GLIM 的预训练逐句 UID 清单也缺失，无法排除预训练阶段与当前测试句子的重叠。

## 3. 既有结果与本轮可作的判断

E1 已有 V3 测试集句子级 Mean Linear Probe：Encoder Macro-F1 0.144、Aligner 0.144；多数类基线 0.144。E1.1 原情感头测试集句子级 Macro-F1 0.241，但预测偏向 Positive；真实 EEG 对分布匹配 Gaussian Noise 没有稳定优势。这些是**既有 V3 结果**，不是本轮新测得的 A0/V3 差值。

| 证据层级 | 结论 |
|---|---|
| 已核实 | V3 权重完整、V3 显式使用情感监督、当前 GLIM 基座源码结构一致、V3/E1 划分一致。 |
| 尚不能判断 | A0 与 V3 连续特征的测试集线性可读性差异、真实 EEG 相对噪声/错配 EEG 的两模型差值。 |
| 不能归因 | V3 与任何已训练 A0 的差异是否由情感监督造成；VQ、属性注入、初始化、训练步数及随机性均可能干扰。 |

## 4. 最小严格消融

先取得独立 A0 checkpoint、SHA256、训练配置和句子 manifest，才可依同一 E1 协议做描述性 A0/V3 冻结比较。因果检验建议额外训练一条 **V3 无情感损失** 对照：从相同的发布 GLIM 权重、V3 spherical K-means 初始化文件及随机种子出发，用同一模型结构、数据划分、batch size、学习率、精度和训练步数；仅将 `disc_emotion_weight` 从 0.2 改为 0。保持 VQ、属性注入及其他损失一致，并预先决定属性头如何处理无监督 logits，避免额外自由度。对两条 V3 轨迹的相同 step checkpoint 按相同 320/40/40 句协议评估，并报告 EEG−Noise/Paired 差值及句子级 bootstrap CI。本轮**没有启动**这条训练。

## 5. 对 A3.1 的建议

暂不把“情感监督已改善连续 EEG 表征”作为双码本设计的已证实前提。先补齐 A0 权重/划分溯源，再完成上述单变量消融。A3.1 如继续，预注册连续与离散分支的句子级 EEG 对照、每类预测和码本位置偏置检查；码本活跃数只代表利用率，不代表情感语义。

本轮仅新增此 E1.2 审计文件，未改动原项目、E1/E1.1、checkpoint 或训练配置；未运行探针及训练。结束时没有 E1.2 探针或训练进程。实例当前无 `/dev/nvidia*` 设备节点，`nvidia-smi` 以状态码 0 退出但无输出，因此**无法给出显存占用数字**，也无法在当前状态提取新的 GPU 特征。就 E1.2 而言，可以安全关闭实例；其他服务的使用情况不在本轮审计范围内。
